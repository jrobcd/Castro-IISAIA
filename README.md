## Cómo se usa esta estructura

Este `README.md` de la raíz es el **índice**: dice quién soy y qué hay en cada carpeta.

El `README.md` de adentro de cada carpeta es el **informe** de esa entrega: qué construí, cómo lo dirigí y cómo se ejecuta. El `prompts.md` de cada carpeta es el registro de prompts, sin editar.
